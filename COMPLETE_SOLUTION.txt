🔌 API ENDPOINTS

POST /api/sensor-data
  Receive buffered sensor readings from ESP32
  Request: { readings: [...], userId: "optional" }
  Response: { message, received, data }

GET /api/sensor-data/latest?limit=50
  Get latest sensor readings
  Response: Array of readings (PPG, BPM, SpO₂, timestamp)

GET /api/sensor-data/stats
  Get aggregate statistics
  Response: { totalReadings, averageBPM, averageSpO₂, averagePPG }

POST /api/sensor-data/predict
  Predict emotion and get recommendations
  Request: { readings: [{ ppg, bpm, spo2 }] }
  Response: { emotion, confidence, recommendations }

🐛 TROUBLESHOOTING

COM Port Not Found
  → Run: node setup-helper.js
  → Check Device Manager (Windows)
  → Update .env with correct port

Backend Not Running
  → Check: npm run server
  → Verify port 3001 available
  → Check console for errors

No Data in Dashboard
  → Verify serial syncer is receiving data
  → Open Arduino Serial Monitor at 115200
  → Check data format in serial output
  → Check browser console (F12)

API Connection Error
  → Ensure backend running
  → Check .env API_BASE_URL
  → Verify CORS enabled

Model Loading Failed
  → Use heuristic mode (default, no setup)
  → Or convert H5 to TensorFlow.js format
  → See SENSOR_SETUP.md for details

💡 CUSTOMIZATION TIPS

Change Chart Colors (SensorDashboard.js)
  • borderColor: '#YOUR_COLOR'
  • backgroundColor: 'rgba(...)'

Adjust Emotion Thresholds (server/index.js)
  • Modify BPM/SpO₂ ranges in predictEmotion()
  • Change confidence calculation

Modify Recommendations (server/index.js)
  • Edit getMentalHealthRecommendations()
  • Add new suggestions
  • Update resource links

Change Refresh Rate (SensorDashboard.js)
  • setRefreshInterval(milliseconds)
  • Default: 5000ms (5 seconds)

Adjust Buffer Size (serial-syncer.js)
  • const BUFFER_SIZE = 10
  • More frequent: decrease number
  • Less frequent: increase number
