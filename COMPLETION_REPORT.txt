## 🔄 API ENDPOINTS

GET /api/dashboard
  Returns: Latest emotion, stats, averages

POST /api/predict
  Body: { heartRate, o2Level, notes, userId }
  Returns: { emotion, confidence, record }

GET /api/analytics?range=week|month|year
  Returns: Charts data, emotions, trends

GET /api/records
  Returns: All health records

DELETE /api/records/:id
  Returns: Success status

GET /api/health
  Returns: Server status, timestamp
