🧠 EMOTION DETECTION

Pattern-Based Algorithm (Default):
  Relaxed  → Low BPM + High SpO₂ (confidence 85-95%)
  Happy    → Normal BPM + Good SpO₂ (confidence 80-95%)
  Neutral  → Baseline vitals (confidence 50-80%)
  Sad      → Slightly elevated BPM (confidence 70-90%)
  Angry    → High BPM + Lower SpO₂ (confidence 75-90%)

  • Convert H5 to TensorFlow.js format

🔗 API ENDPOINTS

POST /api/sensor-data
  • Receive 10 buffered sensor readings
  • Store in database
  • Returns: { message, received, data }

GET /api/sensor-data/latest?limit=50
  • Get latest sensor readings
  • Default 10, max 50
  • Returns: Array of readings

GET /api/sensor-data/stats
  • Get average BPM, SpO₂, PPG
  • Get total readings count
  • Returns: { averageBPM, averageSpO2, ... }

POST /api/sensor-data/predict
  • Predict emotion from readings
  • Generate recommendations
  • Returns: { emotion, confidence, recommendations }

🐛 QUICK TROUBLESHOOTING

Problem: "Port not found"
Solution: 
  1. Run: node setup-helper.js
  2. Check Device Manager (Windows)
  3. Update .env: SERIAL_PORT=COM11

Problem: "Cannot connect to backend"
Solution:
  1. Verify: npm run server is running
  2. Check: Port 3001 is available
  3. Update: API_BASE_URL in .env

Problem: "No data in dashboard"
Solution:
  1. Check serial syncer receiving data
  2. Open Arduino Serial Monitor at 115200
  3. Verify data format matches parser

Problem: "Test system fails"
Solution: Run npm run test-system
  • Shows what's working
  • Shows what needs fixing
  • Comprehensive diagnostics
